# E-Commerce Sales Analytics

An end-to-end E-Commerce Sales Analytics project built using MySQL, SQL, Power BI, and DAX to analyze sales performance, customer behavior, product performance, payments, reviews, and delivery insights.

## 📊 Project Overview

This project transforms raw e-commerce transaction data into actionable business insights through SQL analysis and an interactive Power BI dashboard.

The project covers:

- Data loading and validation
- Data cleaning and quality checks
- SQL-based business analysis
- Customer analysis and segmentation
- Product and category performance
- Sales and order analysis
- Payment method analysis
- Review analysis
- Delivery performance analysis
- Interactive Power BI dashboards
- DAX measures and time-intelligence analysis
